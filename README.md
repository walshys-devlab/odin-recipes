# Odin Recipes

This project is part of The Odin Project Foundations course.

The goal of this project is to build a basic recipe website using HTML. The website will contain a main page with links to individual recipe pages.

By completing this project, I will demonstrate my understanding of basic HTML and how to structure and organise a simple website.

## Skills I Will Demonstrate

* Creating HTML files
* Using HTML boilerplate
* Using headings and paragraphs
* Creating ordered and unordered lists
* Adding links between pages
* Adding images
* Organising files and folders
* Using relative paths
* Using Git to track changes
* Using GitHub to store the project
